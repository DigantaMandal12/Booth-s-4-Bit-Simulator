About This Mini Project

Complete technical overview, system requirements, limitations, and engineering methodology for the Booth's 4-Bit Multiplication Algorithm Simulator.

Project Overview

This Computer Organization and Architecture (COA) mini project implements an interactive, browser-based simulator for Booth's Multiplication Algorithm restricted to signed 4-bit operands (-8 to +7). It bridges classroom theory and register-level hardware execution by visualizing every arithmetic and shift step in real time.

Project Objectives

  • Demonstrate signed 4-bit two's complement representation accurately.
  • Visualize internal 5-bit Accumulator A, 4-bit Q, 1-bit Q₋₁, and M registers.
  • Execute genuine bit-level binary addition, subtraction, and arithmetic right shifts.
  • Provide step-by-step forward/backward navigation and automated playback.
  • Deliver zero-dependency static hosting compatibility for GitHub Pages.

Key Features

  • Strict validation for integer inputs in [-8, +7].
  • Live 4-bit binary preview for both Multiplicand and Multiplier.
  • Full 4-iteration trace table with active-row highlighting.
  • 5-bit internal accumulator & sign-extended M to handle M = -8 cleanly.
  • Dedicated educational guide, SVG block diagram, and flowchart.

Technology Stack

  • Markup: HTML5 (semantic structure, accessible controls).
  • Styling: CSS3 (CSS Grid, Flexbox, custom properties, responsive breakpoints).
  • Logic: Vanilla JavaScript (ES6+, modular pure-binary arithmetic engine).
  • Diagrams: Scalable Vector Graphics (SVG).
  • Hosting: Static client-side execution / GitHub Pages.

Hardware Requirements

  • Processor: Any modern dual-core CPU (x86_64 or ARM64).
  • RAM: Minimum 2 GB (for running a modern web browser).
  • Storage: Less than 5 MB free disk space.
  • Display: 360px mobile viewport up to 1920×1080+ desktop monitor.

Software Requirements

  • Operating System: Windows 10/11, macOS, Linux, Android, or iOS.
  • Web Browser: Google Chrome, Mozilla Firefox, Microsoft Edge, or Safari (ES6+ support).
  • Code Editor (Development): VS Code or any text editor.
  • Testing Runtime (Optional): Node.js v18+ for running the automated 256-case test suite.

Project Limitations

  • Strictly scoped to signed 4-bit operands (-8 to +7) as required by the project specification.
  • Does not include 8-bit, 16-bit, or floating-point multiplication modes.
  • Client-side only; simulation histories are not persisted to a backend database.

Future Improvements

  • Add selectable bit-width modes (8-bit and 16-bit) for advanced COA study.
  • Support Modified Booth (Radix-4) encoding comparison.
  • Add interactive quiz mode and downloadable CSV/PDF step traces.

Development Methodology & Architecture

The project follows an iterative modular engineering workflow: separating presentation (HTML5), visual design (CSS3), and bit-level computation (Vanilla JS). All 256 possible input combinations (16 × 16) are verified against a mathematical oracle in Node.js.
