Understanding Booth's Multiplication Algorithm

A beginner-friendly walkthrough of how processors multiply signed binary numbers using two's complement representation, bit-pair inspection, and arithmetic right shifts.

Try It in the Simulator

What Is Booth's Multiplication Algorithm?

Proposed by Andrew Donald Booth in 1950, Booth's Algorithm is a binary multiplication technique that multiplies two signed integers in two's complement notation.

Instead of treating positive and negative numbers separately, it examines adjacent bits of the multiplier (Q₀ and Q₋₁) to decide whether to add, subtract, or skip, followed by an arithmetic right shift.

Why Is It Used?

  • Handles Signed Numbers Directly: Works seamlessly for positive, negative, and zero operands.
  • Fewer Additions for Runs of 1s: A block of consecutive 1s (e.g., 0111₂ = 7) is replaced by one subtraction at the start and one addition at the end (8 - 1 = 7).
  • Uniform Hardware Control: Uses fixed-width registers, an adder/subtractor, and a shifter.

Binary & Two's Complement Basics

In signed 4-bit two's complement, the Most Significant Bit (MSB) acts as the sign bit (0 = non-negative, 1 = negative), giving a range of -8 to +7:

  • Positive numbers (0 to +7): Standard binary (e.g., +3 = 0011₂).
  • Negative numbers (-1 to -8): Invert all bits of the magnitude and add 1.
  • Example for -5: +5 = 0101₂ → invert → 1010 → add 1 → 1011₂.

Registers Used in 4-Bit Booth's Algorithm

  • Accumulator (A — 5 bits internal): Holds partial products, initialized to 00000. Using 5 bits avoids overflow when M = -8.
  • Multiplier (Q — 4 bits): Holds the 4-bit multiplier; shifts right each cycle.
  • Previous Bit (Q₋₁ — 1 bit): Stores the bit shifted out of Q₀, initialized to 0.
  • Multiplicand (M — 4 bits, sign-extended to 5 bits): Added to or subtracted from A.

Decision Table

Q₀ Q₋₁ Operation Meaning
0 0 No Operation Inside a run of 0s — shift only
0 1 A = A + M End of a run of 1s — add M, then shift
1 0 A = A - M Start of a run of 1s — subtract M, then shift
1 1 No Operation Inside a run of 1s — shift only

Arithmetic Right Shift (ARS)

After the decision step, the combined 10-bit register [A (5 bits) | Q (4 bits) | Q₋₁ (1 bit)] is shifted right by 1 position:

  • The sign bit A[0] is preserved (copied into itself).
  • The least significant bit of A shifts into the MSB of Q.
  • The least significant bit of Q (Q₀) shifts into Q₋₁.

Example: [11011 | 0011 | 0] → ARS → [11101 | 1001 | 1].

Step-by-Step Algorithm (4 Iterations)

  1. Initialize A = 00000, load 4-bit multiplier into Q, set Q₋₁ = 0, and sign-extend M to 5 bits.
  2. Inspect the bit pair Q₀Q₋₁.
  3. Perform A = A + M (if 01), A = A - M (if 10), or no operation (if 00 or 11).
  4. Perform an Arithmetic Right Shift on [A, Q, Q₋₁] while preserving A's sign bit.
  5. Repeat Steps 2–4 exactly four times.
  6. Form the final 8-bit signed product using the lower 4 bits of A followed by Q.

Fully Solved Example: M = -5 (1011), Q = 3 (0011)

Sign-extended M = 11011, two's complement -M = 00101. Initial: A = 00000, Q = 0011, Q₋₁ = 0.

Iteration Q₀ Q₋₁ Operation A After Op A After ARS Q After ARS Q₋₁ After ARS
#1 1 0 A = A - M (00000 + 00101) 00101 00010 1001 1
#2 1 1 No Operation 00010 00001 0100 1
#3 0 1 A = A + M (00001 + 11011) 11100 11110 0010 0
#4 0 0 No Operation 11110 11111 0001 0

Final Result: Lower 4 bits of A (1111) + Q (0001) = 11110001₂ = -15₁₀.
