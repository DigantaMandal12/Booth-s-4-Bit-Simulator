Booth's Multiplication Algorithm Simulator (Signed 4-Bit)

An interactive educational web simulator designed to visualize signed 4-bit binary multiplication using Booth's Algorithm. Observe two's complement conversion, register initialization, addition/subtraction decisions, arithmetic right shifts, and final 8-bit product generation step by step.

Open Simulator Learn Algorithm About Project

Objective of Booth's Algorithm

Booth's Multiplication Algorithm provides a systematic hardware-level method to multiply two signed binary integers represented in two's complement form without converting negative operands to positive magnitudes first.

By inspecting consecutive multiplier bit pairs (Q₀ and Q₋₁) across four iterations, it reduces consecutive ones into a single subtraction and addition, making signed arithmetic uniform and efficient in processor ALUs.

Strict 4-Bit Signed Input Range

This simulator exclusively models signed 4-bit two's complement arithmetic:

  • Minimum Input: -8 (1000₂)
  • Maximum Input: +7 (0111₂)
  • Output Width: 8-bit (-56 to +64)
  • Iterations: Exactly 4 Cycles

Internally, a 5-bit Accumulator (A) and sign-extended 5-bit Multiplicand (M) prevent overflow during edge cases such as -8 × -8 = +64.

Key Simulator Features

Live Binary Conversion

Automatically converts signed decimal inputs M and Q into 4-bit two's complement binary representations as you type.

Bit-Level Register View

Displays 5-bit Accumulator A, 4-bit Multiplier Q, 1-bit Q₋₁, and Multiplicand M with sign-bit and LSB highlighting.

Step-by-Step Controls

Start, Reset, step forward or backward through each iteration, or auto-play and pause all four cycles with detailed explanations.

Example Multiplication: -5 × 3 = -15

Multiplicand (M): -5 → 1011₂ (5-bit: 11011₂)
Multiplier (Q):   3 → 0011₂
Initial State: A = 00000, Q = 0011, Q₋₁ = 0
After 4 Iterations:
Lower 4 bits of A = 1111, Q = 0001
Final 8-bit Product: 11110001₂ = -15₁₀
